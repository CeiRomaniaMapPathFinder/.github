# Romania Map Pathfinder

Pick two cities on the Romania map and watch **Breadth-First Search** and **A\*** find a route side by side.

**Live demo:** https://ai-pathfinder.kimlarp.xyz

## What it does

- Choose a start and a goal city on the map
- Watch BFS and A\* expand the map step by step
- Compare path cost, nodes expanded, peak nodes stored, search time and memory
- Explore A\*'s search tree and how its xGT heuristic works
